# Python Fundamentals Assignments

Two Jupyter notebooks covering Python's date and time tools and a basic library management system.

## Notebooks

### Assignment 01 — Date, Time, and Datetime

Practice with Python's `date`, `time`, and `datetime` modules, including formatting date and time values and working with timestamps.

### Assignment 02 — Library Management System

A menu-driven program for managing a small in-memory library. Features include:

- Viewing and searching books
- Adding, editing, and deleting books
- Issuing and returning books

The notebook demonstrates functions, lists, dictionaries, loops, and conditional statements.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab

The notebooks use Python's standard library.

## Getting started

Open either notebook in Jupyter and run its cells in order. The library data is stored in memory, so changes are not saved after the program ends.
